# 运行测试指南

## 📁 项目结构
```
RealTimeDataMonitorDemoRewritebyHand/
├── test/
│   ├── server.py                    # gRPC服务器
│   ├── test_subscribe_basic.py      # SubscribeTelemetry测试
│   └── test_communication.py        # 基础通信测试
├── app/
│   ├── grpc_server.py              # 服务器实现
│   └── grpc_client.py              # 客户端实现
└── generated/                       # protobuf生成的代码
```

## 🚀 步骤1：启动服务器

**在第一个终端窗口中：**
```bash
# 进入项目目录
cd RealTimeDataMonitorDemoRewritebyHand

# 启动gRPC服务器
python -m test.server
```

看到以下输出表示启动成功：
```
[gRPC] Server started on localhost:50051 (insecure)
```

## 🧪 步骤2：运行测试

**在第二个终端窗口中：**
```bash
# 进入项目目录
cd RealTimeDataMonitorDemoRewritebyHand

# 运行基础通信测试
python -m app.grpc_client

# 运行订阅功能测试
python -m test.test_subscribe_basic

# 运行完整通信测试
python -m test.test_communication
```

## ⚠️ 常见错误和解决方案

### 1. 模块导入错误
❌ **错误用法：**
```bash
python -m test\test_subscribe_basic.py
python -m test/test_subscribe_basic.py
```

✅ **正确用法：**
```bash
python -m test.test_subscribe_basic
```

### 2. 连接被拒绝错误
❌ **错误信息：**
```
Connection refused (No connection could be made because the target machine actively refused it.)
```

✅ **解决方案：**
- 确保服务器已启动（步骤1）
- 检查端口50051是否被占用
- 确保防火墙没有阻止本地连接

### 3. 模块找不到错误
❌ **错误信息：**
```
ModuleNotFoundError: No module named 'test\\test_subscribe_basic'
```

✅ **解决方案：**
- 确保在项目根目录执行命令
- 使用点号分隔符：`test.test_subscribe_basic`
- 不要包含 `.py` 后缀

## 💡 学习要点

1. **服务器流概念**：客户端发送一个请求，服务器持续推送多个响应
2. **过滤机制**：服务器根据过滤条件筛选要推送的数据
3. **项目结构**：测试文件放在 `test/` 目录，遵循标准Python项目结构
4. **模块导入**：使用 `python -m package.module` 的标准模块运行方式
